## Freight & Transport Management

Open platforms, API suites, and software architectures designed for multimodal freight booking, rate management, and carrier tracking.

- [Open-TMS](https://github.com/open-tms) — Open-source transportation management system for managing shipments, carrier rates, and bill of lading documents.
- [Project44 Developer Network](https://www.project44.com/) — Enterprise real-time transportation visibility platform providing APIs for global multi-modal shipment tracking.
- [Freightos API Suite](https://www.freightos.com/) — International freight rate digitization and digital booking APIs for ocean, air, and trucking logistics.
- [Flexport Developer Platform](https://www.flexport.com/) — API ecosystem for modern freight forwarding, customs clearance, and container tracking.

## Last-Mile & Parcel Delivery

Software libraries, dispatch engines, and status aggregators built for courier tracking, route execution, and proof-of-delivery capture.

- [EasyPost API Libraries](https://github.com/EasyPost) — Multi-carrier shipping integration platform providing standardized APIs for postage generation and parcel tracking.
- [Shippo Client Kits](https://github.com/goshippo) — Open SDKs for integrating e-commerce storefronts with major global shipping carriers and label printers.
- [Open-Delivery-Dispatch](https://github.com/lastmile-dev) — Open dispatch and driver mobile application framework designed for urban last-mile delivery fleets.
- [Proof-of-Delivery-App](https://github.com/pod-open) — Open-source mobile interface for capturing digital signatures, GPS timestamps, and delivery photo verifications.

## Logistics Interoperability & EDI

Standards, parsing libraries, and data translation pipelines for EDIFACT, ANSI X12, and modern JSON freight protocols.

- [Stedi EDI Parsers](https://github.com/stedi) — Modern cloud infrastructure and developer tools for parsing ANSI X12 (EDI 214, 204, 210) transactions.
- [Bots EDI Translator](https://github.com/bots-edi/bots) — Complete open-source EDI (Electronic Data Interchange) translator supporting X12, EDIFACT, XML, and JSON formats.
- [Open-X12](https://github.com/open-x12) — Lightweight parser engine for validating and generating freight and logistics EDI files.

## Warehouse & Fulfillment Integration

Middleware, event protocols, and routing systems linking order management software to physical distribution hubs.

### Inventory & Stock Movement

- [OpenWMS Core](https://github.com/openwms) — Modular open-source warehouse management platform built to coordinate stock movements and warehouse control systems.

### Fulfillment Automation

- [Order-Routing-Engine](https://github.com/fulfillment-ops) — Open-source rule engine designed to route customer orders to the optimal warehouse based on stock levels and proximity.
